# Language and localization standards
- English is the primary default language for code, documentation, communication, architecture, and user interfaces.
- Support Arabic and additional languages when requested by the user or required by project specifications.
- When Arabic or multilingual support is requested, test Arabic RTL and English LTR layouts, typography, mixed-direction strings, dates, numbers, forms, and accessibility.
- Use native, audience-appropriate localization; avoid literal translations that distort meaning.
