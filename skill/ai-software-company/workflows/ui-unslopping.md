# UI Unslopping & Interface Craft Lifecycle (heydamir/unslop)

This workflow defines the mandatory UI refinement gate based on Damir Sokolovsky's **[heydamir/unslop](https://github.com/heydamir/unslop)**. Every web application, dashboard, landing page, and UI component generated by the company must complete this process before progressing to QA and Code Review.

---

## 1. Visual Ingestion & Slop Audit
1. Render the interface in a browser or inspect the component markup/Tailwind classes.
2. Conduct an audit against the classic **Signs of Slop**:
   - Purple/blue gradients on cards, buttons, or active navigation.
   - Gradient text or shimmering headings.
   - Colored glows (`shadow-[0_0_20px_...]`) or blurred radial blobs behind content.
   - Emoji used as navigation icons, status indicators, or decorative tags.
   - Arbitrary pixel values (`mt-[13px]`, `w-[31px]`) breaking the 4px rhythm.
   - AI marketing hype copy (`supercharge`, `seamless`, `unlock`, `revolutionize`).
   - Glowing pills, rainbow charts, and excessive `✨ New` badges.

## 2. Setting the 5-Line Direction
Before modifying any CSS or markup, define the product's design foundation:
- **Product:** Exactly what the product does and for whom in one sentence.
- **Character:** 2–3 concrete traits (e.g. `fast, technical, understated`; forbidden: clean, modern, sleek).
- **World:** The physical environment or material the product belongs to (e.g. instruments, paper, architectural blueprints).
- **Moments:** 1–2 specific places where the interface gets rich, deliberate color and detail.
- **Signature:** Exactly one subtle, unique micro-detail used consistently across the product.

## 3. The 9-Pass Sequential Refactoring
Execute all nine passes across the entire screen in strict order:

1. **Pass 1 — Spacing:**
   - Snap all paddings, margins, gaps, and heights to the **4px scale** (4, 8, 12, 16, 20, 24, 32, 48px).
   - Ensure identical rows and cards share identical heights and padding.
2. **Pass 2 — Color & Chrome:**
   - Establish one neutral ramp (tinted toward the product's world).
   - Set chrome, backgrounds, and cards to neutral surfaces with quiet hairlines (text at 6–10% opacity).
   - Use exactly one accent color sparingly for primary actions; ensure 4.5:1 text contrast.
   - Delete all colored glows, gradient text, and radial background washes.
3. **Pass 3 — Icons:**
   - Replace every emoji in navigation and badges with Lucide line icons (16px or 18px with 1.5px stroke).
   - Inherit text colors (secondary/muted); remove unique rainbow icon colors.
4. **Pass 4 — Copy:**
   - Replace marketing hype with concise, factual, confident copy.
   - Strip exclamation marks, wordy placeholders, and trailing periods on buttons.
5. **Pass 5 — Typography:**
   - Constrain to at most 2 font families. Headings use weights 400–500; size carries hierarchy.
   - Convert all-caps tracked labels (`STATUS`) to sentence case.
6. **Pass 6 — Layout:**
   - Place headlines and primary CTAs over calm, uncluttered negative space.
   - Avoid generic centered stacks; balance components using structured grids.
7. **Pass 7 — Details & Micro-Craft:**
   - Enforce nested border radius (`inner_radius = outer_radius - padding`).
   - Use subtle surface depth transitions rather than heavy colored drop shadows.
8. **Pass 8 — Visuals:**
   - Anchor the screen with **one bright element** (a realistic chart, physical object, or product preview).
9. **Pass 9 — Motion:**
   - Keep interactive transitions fast and functional ($\le 200\text{ms}$); eliminate floating blobs and gratuitous scroll animations.

## 4. Verification & Handoff
- Re-check against the slop signs list.
- Produce the `UNSLOP_AUDIT_REPORT.md` documenting the 5-line direction and before/after improvements.
- Hand off the refactored code to the **QA Testing Engineer** and **Code Reviewer**.
