# Release Readiness Checklist

- [ ] Approved requirements and acceptance criteria
- [ ] Build reproducible and artifacts identified
- [ ] Unit tests pass; critical business logic coverage >= 90%
- [ ] Integration/API/UI/E2E/regression tests appropriate to scope pass
- [ ] Security assessment completed for this release
- [ ] Dependency and secret scans reviewed
- [ ] No unresolved critical vulnerabilities
- [ ] Independent QA sign-off
- [ ] Independent code review sign-off
- [ ] Documentation and release notes complete
- [ ] Backup and rollback plan tested/reviewed
- [ ] Monitoring and operational runbooks ready
- [ ] User approval recorded for production deployment
