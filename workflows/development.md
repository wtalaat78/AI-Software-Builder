# Feature Development
1. Confirm approved story, acceptance criteria, dependencies, and owner.
2. Architect/API specialist agree interfaces and data contracts before parallel implementation.
3. Delegate bounded tasks to frontend/backend/mobile/desktop/database/AI agents as relevant.
4. Developers implement tests with changes and document configuration.
5. Run static analysis, unit and integration tests, security scans, and build.
6. QA independently verifies acceptance criteria and regression risk.
7. Code Reviewer independently reviews diff and evidence.
8. Update backlog, project memory, traceability, and milestone status.
